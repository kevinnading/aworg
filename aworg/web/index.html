Appearance

You will be looking at this for as long as the Resident is yours. Pick a scheme, or change any colour in it.

The Resident

Which mind the Resident thinks with, which one its workers think with, and the standing instructions that describe who it is. The instructions belong to the Resident, not to the model — change the model and it carries on as itself.

Persona

Who your Resident is and how it presents itself — its name, its manner, and the look of the chat it lives in. Changing it does not make a new Resident: the conversation, the plan, the Living Log, the workers and every permission stay exactly as they are. It is the same inhabitant, differently.

A Persona is a folder — PERSONA.md, a theme.json, and an avatar — so writing one is writing a page of Markdown. Drop it in personas/ under this Aworg's home and it appears here. Nothing in a Persona can widen what the Resident is allowed to do.

Model Pool

Every model this Aworg can reach. A connection is one model and how to reach it — never a personality. Who is using it, and how, is set above.

Password

One password and no username — there is one owner here. It was generated and printed in the terminal the first time this Aworg started, and it is kept as a hash, so nothing can read it back. Changing it signs out every browser that is signed in, including this one.

Lost it? Run aworg password on the machine this runs on. It sets a new one and prints it.
